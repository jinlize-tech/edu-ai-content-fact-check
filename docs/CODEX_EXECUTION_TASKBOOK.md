# JLZ-EDU-SK-095 Codex执行任务书

## 1. 基线

- 任务编号：`JLZ-EDU-EXPANSION-30-FULL-DELIVERY`
- 候选来源：`CAND-051`
- 正式产品：`JLZ-EDU-SK-095` / AI生成教学内容事实核验
- 类型：Skill
- 批次：2
- 业务中心：15 数字治理与AI合规中心
- 版本基线：`EDUCATION_BASELINE_V1.0.0`
- 产品版本：`1.0.0`
- 许可证：Apache-2.0

## 2. 用户、痛点与目标

- 用户：教师、教研、内容审核员、教学主管
- 痛点：AI生成教案、题目和讲解速度快，但可能编造来源、过时知识、错误答案或不适龄内容。
- 目标：对AI生成的教学材料做事实、计算、引用、适龄性和内部一致性核验，标记需外部权威来源确认的项。

## 3. 输入契约

| 键 | 名称 | 类型 | 必填 |
|---|---|---|---|
| `ai_generated_content` | AI生成教学内容 | string | 是 |
| `grade_subject` | 年级与学科 | string | 是 |
| `curriculum_scope` | 教材与课程标准范围 | string | 是 |
| `allowed_sources` | 允许使用的来源 | array | 否 |
| `answer_key` | 参考答案 | string | 否 |
| `target_age` | 目标年龄 | string | 是 |
| `intended_use` | 用途 | string | 是 |

## 4. 工作流

1. 拆分断言
2. 分类可内部核验/需外部来源
3. 检查计算和逻辑
4. 对照用户材料
5. 标记未证实项
6. 输出修订与复核

## 5. 阶段状态

| 阶段 | 动作 | 退出成果 |
|---|---|---|
| S1_SCOPE_CONFIRMATION | 确认目标、校区/岗位/课程范围、期限、交付格式和可用资料。 | 任务确认单与最多3个关键缺口 |
| S2_EVIDENCE_INVENTORY | 盘点AI生成内容、年级学科、课程标准/教材范围、允许使用的来源、参考答案、审核用途，标记来源、版本、敏感字段与冲突。 | 证据清单、缺口表和冲突表 |
| S3_PROFESSIONAL_DIAGNOSIS | 围绕对AI生成的教学材料做事实、计算、引用、适龄性和内部一致性核验，标记需外部权威来源确认的项。进行专业诊断，形成问题树和优先级。 | 问题树、风险和优先级 |
| S4_SOLUTION_DESIGN | 按拆分断言 → 分类可内部核验/需外部来源 → 检查计算和逻辑 → 对照用户材料 → 标记未证实项 → 输出修订与复核设计首选方案和受限备选方案。 | 方案、责任人、完成标准 |
| S5_HUMAN_CONFIRMATION | 由业务负责人复核输入事实、关键假设和最终成果适用范围。 | 确认记录、未决项和升级项 |
| S6_FINAL_DELIVERY | 生成完整交付成果，执行结构、证据、安全、品牌和独立安装检查。 | 最终成果、范围限制和复盘指标 |

## 6. 核心成果

- `事实核验表`
- `错误/待核实项`
- `发布建议`

## 7. 差异化与排重

- 与现有产品：教案审查看教学设计；本产品专门审查AI内容的事实和来源可靠性，可前置任何教学发布。
- 排重检查：部分重叠；共享教学内容输入，但本产品输出事实核验和来源风险。
- 独立理由：无需现行课程产品即可单独核验AI内容。

## 8. 安全与人工门禁

- 复核角色：业务负责人
- 复核范围：输入事实、关键假设和最终成果适用范围
- 不调用外部收费API。
- 不自动修改外部系统、执行退款、审批合同、处分员工或联系外部人员。
- 高风险产品完成状态必须确认人工复核。

## 9. 测试
