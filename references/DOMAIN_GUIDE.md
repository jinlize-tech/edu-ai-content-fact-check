# AI生成教学内容事实核验领域指南

## 业务问题

AI生成教案、题目和讲解速度快，但可能编造来源、过时知识、错误答案或不适龄内容。

## 产品解决方案

对AI生成的教学材料做事实、计算、引用、适龄性和内部一致性核验，标记需外部权威来源确认的项。

## 输入质量要求

| 字段 | 名称 | 必填 | 质量要求 |
|---|---|---|---|
| `ai_generated_content` | AI生成教学内容 | 是 | 待核验原文 |
| `grade_subject` | 年级与学科 | 是 | 用于适龄和学科规则 |
| `curriculum_scope` | 教材与课程标准范围 | 是 | 限定知识范围 |
| `allowed_sources` | 允许使用的来源 | 否 | 用户提供或机构批准的权威来源 |
| `answer_key` | 参考答案 | 否 | 便于内部核验 |
| `target_age` | 目标年龄 | 是 | 内容适龄性边界 |
| `intended_use` | 用途 | 是 | 课堂、作业、公开材料或营销 |

## 证据判断

- 用户原文优先于模型推断。
- 外部政策或公开事实应记录标题、发布机构、发布日期、URL、访问日期和适用范围。
- 无法核验时标记`EVIDENCE_UNVERIFIED`，不补造来源。
- 数据冲突必须并列展示，并说明对结论的影响。

## 人工复核

业务负责人应确认：输入事实、关键假设和最终成果适用范围。未经确认的内容只能作为草案。

## 主要风险

模型无法证明所有事实；可能依赖不完整资料；必须区分无法核验与确定错误；重要知识需权威来源和教师确认。
